# AAA-python-homework

Консольная программа читает файл `Corp_Summary.csv` с данными о сотрудниках и умеет:

1. вывести иерархию команд: департамент и все входящие в него отделы;
2. вывести сводный отчёт по департаментам: численность, максимальная, минимальная и средняя зарплата;
3. сохранить сводный отчёт в файл `output.csv`.

## Установка

Нужен Python 3.9+. Сторонние зависимости не требуются, используются только модули стандартной библиотеки (`csv`, `itertools`, `collections`).

```bash
git clone <ссылка на репозиторий>
cd <папка репозитория>
```

## Запуск

Положите `Corp_Summary.csv` в одну папку со скриптом и выполните:

```bash
python main.py
```

Затем введите номер действия (1, 2 или 3).

## Формат входных данных

- CSV с разделителем `;` и строкой заголовка в первой строке;
- кодировка UTF-8;
- департамент находится во втором столбце, отдел в третьем, зарплата в шестом.

## Результат

Для пункта 3 создаётся файл `output.csv` (разделитель `;`, кодировка UTF-8 с BOM, чтобы он корректно открывался в Excel) со столбцами: департамент, количество сотрудников, максимальная, минимальная и средняя зарплата.
