# Анализ данных о Нобелевских лауреатах

Учебный проект по Python: я собрала данные о лауреатах из API Нобелевской премии, привела их к плоскому виду и проанализировала без pandas и numpy.

## Что внутри

- **Этап 1.** Загрузка данных из API и обработка вложенных словарей по конфигам.
- **Этап 2.** EDA: количество записей, пропуски, проверка `id`.
- **Анализ.** Три темы: топ стран по числу лауреатов, возраст при первом призе, женщины-лауреатки по десятилетиям.

Выводы и графики лежат в ноутбуке `laureates_countries_task.ipynb`.

## Как запустить

1. Нужен Python 3.12 и библиотеки `requests` и `matplotlib`:
pip install requests matplotlib
2. Откройте ноутбук из корня папки `finalTask` (иначе пакет `preparing_data` не найдётся).
3. Выполните `Kernel → Restart & Run All`. Нужен интернет: данные скачиваются с `https://api.nobelprize.org/2.1/laureates`.

## Особенности и ограничения

- Для категорий и десятилетий я учитывала только **первый** приз лауреата.
- Страна берётся из поля `country_now` (страна на сегодняшний день).
- Данные за 2020-е годы неполные, десятилетие ещё не закончилось.
- Если API отвечает ошибкой 403, нужен заголовок `User-Agent` (он уже есть в коде) или другая сеть.
